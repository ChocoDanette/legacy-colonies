# Legacy Colonies

MineColonies addon for the TerraFirmaCraft Legacy modpack (Minecraft 1.21.1, NeoForge 21.1, MineColonies 1.1.1403).

GitHub Actions builds the jar on every push: open the latest run in the Actions tab and download `legacycolonies-jar`.
Local build: `gradle build` (Gradle 8.10+, Java 21). The jar is written to `build/libs/`.
